   # 🚦 Traffic Violation Detection System

The system provides real-time vehicle monitoring, violation analytics, and reporting through an interactive dashboard.

## 🚀 Installation

### Prerequisites

- Node.js (v18 or above)

### Clone Repository

```bash
git clone https://github.com/dhanuprabu/Traffic-Violation-Detection.git
```

### Install Dependencies

```bash
npm install
```

### Configure Environment

Create a `.env.local` file and add your required configuration values.

Example:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
```

### Run the Application

```bash
npm run dev
```
